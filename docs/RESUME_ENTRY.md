# Resume project entry

**Student Academic Performance Prediction | Machine Learning Project**  
Auburn University, COMP 1100 | Fall 2026  
**Tools:** WEKA, Microsoft Excel, machine learning, data analysis

- Evaluated four classification configurations using J48 Decision Trees and Logistic Regression on 395 student records, with 10-fold cross-validation.
- Prepared and verified two feature sets with and without first-period grades to measure the impact of prior academic performance on final pass/fail prediction.
- Achieved **84.3% accuracy** with G1, improving accuracy by approximately 16–18 percentage points over the same algorithms without grades.
- Analyzed confusion matrices, precision, Fail recall and ROC AUC; the strongest model identified **101 of 130 students who failed**.
